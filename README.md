# ダメ計 — ポケモンダメージ計算ツール

スマホ対応のポケモンダメージ／耐久計算ツールです。

- Lv50・個体値31固定
- 努力値は **合計66 / 1項最大32**（32振りボタンあり）
- 実数値: **HP = 種族値+75+努力値** / **他 = floor((種族値+20+努力値)×性格)**
- 攻撃側は攻撃・特攻のみ、防御側は HP・防御・特防のみ表示
- 性格は上昇×下降の表から選択（赤▲青▼）
- 特性（複数時は切替）・能力ランク・持ち物
- 天候・フィールド・壁・急所・ステロ等
- 結果表示: `〇％～〇％　確定〇発` / `乱数〇発（％）`

## データ

提供データを `data/` に格納しています（改変なし）。

- `pokemon.json` … `po.txt` から抽出
- `moves.json` … 提供技一覧
- `items.json` … 提供持ち物一覧（メガストーン除外）
