# ダメ計 — ポケモンダメージ計算ツール

スマホ対応のポケモンダメージ／耐久計算ツールです。

- Lv50・個体値31固定
- 努力値・性格・特性（複数時は切替）・能力ランク・持ち物
- 天候・フィールド・壁・急所・ステロ等
- 結果表示: `〇％～〇％　確定〇発` / `乱数〇発`
- 種族値・実数値を選択後に確認可能

## 使い方（スマホ）

GitHub Pages で公開した URL をブラウザで開いてください。

## ローカル

```bash
# 任意の静的サーバ
npx --yes serve .
```

## データ

提供データを `data/` に格納しています（改変なし）。

- `pokemon.json` … `po.txt` から抽出
- `moves.json` … 提供技一覧
- `items.json` … 提供持ち物一覧（メガストーン除外）
